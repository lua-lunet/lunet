## 要点

- **新扩展：`ext/http` —— 每个应用都在重新发明的 HTTP 处理。**
  `lunet.http`（keep-alive 请求帧、JSON 响应、错误形状）、
  `lunet.http_context`（请求/响应上下文），以及 `lunet.http_router`
  （方法+模式路由、`:param` 捕获、require 时注册路由、经 `router.use(fn)`
  的派发前中间件链，以及默认关闭的可选 CORS）—— 纯 Lua，构建在
  `lunet.socket` 之上；示例 `examples/08_http.lua`（HTTP 服务器 +
  `lnt_shared` 计数器充当刻意简单的 kv：GET 读、POST 加、PATCH 调）。旧
  的 `08_lnt_shared.lua` 已被吸收。完整参考：`docs/HTTP-CN.md` / `HTTP.md`。
- **新扩展：`ext/security` —— 构建在链接的 libsodium 之上的 crypto 与 JWT。**
  `require("lunet.security")` 返回 `crypto`（HMAC-SHA-256 签名/校验、常数时
  间比较、base64url 助手）与 `jwt`（HS256 编码/解码/校验：类型检查的
  header 与 payload、强制 `exp`、命名的错误）。构建在既有的 `lunet.sodium`
  与 `lunet.jsonic` 表面之上——零新依赖；随压缩包发布。完整参考：
  `docs/SECURITY-CN.md` / `SECURITY.md`。
- **演示舰队有了自己的文章。** `examples/realworld/README-CN.md` / `README.md`
  现在写出理念（不要厨房水槽——但演示证明全谱系都做得到），并附上演示应用
  的表格——twelve-dollar-server-challenge 提交（开发者机器上的非官方观察：
  运行该 feed API 的常驻内存约 4 MB）、realworld-lua、lunet-mcp-sse（开销：
  171 MB 镜像 / 7 MB 运行时）、lunet-backproxy 的 DMZ 模式，以及仓库内的
  `mcp_openalex_sse` 演示——外加随仓库发布的演示文件索引。
- **每个扩展一份规格测试。** 补齐 `spec/jsonic_spec.lua` 与
  `spec/lnt_shared_spec.lua`——现在每个扩展模块都有以自己名字命名的规格文
  件，busted 套件翻倍（222 项全绿）。
