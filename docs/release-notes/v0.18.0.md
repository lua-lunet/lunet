- mysql.open gains open-time TLS passthrough, mirroring the postgres driver's sslmode design: `ssl_ca`, `ssl_capath`, `ssl_cert`, `ssl_key`, `ssl_cipher`, `ssl_crl`, `ssl_crlpath`, `tls_version`, plus `ssl_mode` (mysqlclient) and `ssl_verify_server_cert` (libmariadb). Unset keys leave the vendor library default untouched; wrong types and non-whitelisted values fail loudly at open time.
- The mysql client-library floor is raised to the supported LTS client lines: mysqlclient >= 8.0 (Oracle) and libmariadb >= 3.4 (MariaDB Connector/C), enforced at compile time with a named error. Newer clients remain backwards compatible with older servers; the raise prunes the removed legacy option surface (`MYSQL_OPT_SSL_VERIFY_SERVER_CERT` and `MYSQL_OPT_SSL_ENFORCE`) instead of cutting off older servers. The libmariadb floor checks the connector package version (`MARIADB_PACKAGE_VERSION_ID`), not the server version the same macro reports in server-bundled builds.
- Eight per-extension build flags (`lunet_ext_paxe`, `lunet_ext_crypto`, `lunet_ext_lnt_shared`, `lunet_ext_jsonic`, `lunet_ext_sqlite3`, `lunet_ext_mysql`, `lunet_ext_postgres`, `lunet_ext_httpc`), all default ON, gate each extension's build and its specs in the test chain — a machine without cargo, or a build that only wants the database drivers, can exclude the rest without touching CI, where every flag stays ON.
