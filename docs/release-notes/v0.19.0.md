The 0.19 line opens with a correctness fix in the outbound HTTP client.

## Highlights

### httpc

- `httpc.request` sends a real HEAD request: `method = "HEAD"` sets libcurl's
  `CURLOPT_NOBODY`, so the response returns as soon as the header block
  arrives — status and headers with an empty body — instead of blocking
  until the request timeout while libcurl waited for a response body that a
  HEAD response never carries. `CURLOPT_CUSTOMREQUEST` alone only rewrote
  the request line and left libcurl's GET-like body expectation in place.
- Proven by a new loopback smoke, `test/smoke_httpc_head.lua`: its raw
  server answers HEAD with `Content-Length` and no body and records the
  request line seen on the wire, so the test fails with the timeout symptom
  on the old build, passes on the new one, and cannot pass with the method
  silently downgraded to GET. It runs in CI on Linux, macOS, and Windows.
