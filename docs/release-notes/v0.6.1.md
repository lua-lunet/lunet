- **Linux arm64 release archives** (#125): the release workflow now produces `lunet-linux-arm64.tar.gz` and `lunet-linux-arm64-sdk.tar.gz` alongside the existing amd64 archives. The arm64 build runs natively on Blacksmith's `blacksmith-4vcpu-ubuntu-2404-arm` runner — no emulation. This closes the gap for downstream projects like `lunet-dav` that consume the prebuilt release archives in CI and want to publish arm64 Linux binaries without a full from-source build.
- **`workflow_dispatch` target filter**: the manual workflow dispatch now accepts a `targets` input (comma-separated: `linux-amd64`, `linux-arm64`, `macos`, `windows`) for selective debug builds. When empty (the default), all targets build — preserving the existing behavior for PRs and tag releases.
- **PAXE smoke test gated on AES-256-GCM hardware availability**: the Blacksmith arm64 runner does not expose ARMv8 crypto extensions to the VM, so `crypto_aead_aes256gcm_is_available()` returns 0. The PAXE example smoke step now checks hardware support before running; it skips only that step when unavailable. All other steps still fail on error — no error swallowing.
