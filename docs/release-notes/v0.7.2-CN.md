- **覆盖完整公共 API 的 LuaCATS 类型注解**(#135、#136、#137、#138):`types/lunet/*.lua` 现在为所有已发布的模块提供了注解——包括此前缺失的 `lnt_shared`(2 个模块函数 + 13 个方法的 Dict 对象)、`httpc`、`jsonic`、`postgres` 和 `paxe`——每个文件都配有按仓库规则保持同步的 Teal `.d.tl` 镜像。这些注解作为文档随所有二进制发布归档一起分发,并由新的 CI 门禁使用 lua-language-server 进行验证:`xmake check-types` 解析 JSON 报告(LuaLS 3.15+ 即使存在诊断也返回 0),任何警告级诊断都会导致失败。
- **诚实的 Lua 测试门禁**:`make test` 现在先运行 `check-types`,再构建 `lunet-httpc`,然后在 LuaJIT(5.1 ABI)下运行 busted 测试套件——解释器按 `$LUNET_BUSTED` → `~/.luarocks/bin/busted` → PATH 的顺序解析,因为 Homebrew 和 Debian 的 luarocks busted 包装脚本都会 exec PUC Lua,加载 lunet 的 LuaJIT 链接 C 模块时会挂起。任何 `pending` 测试都会导致运行失败(`LUNET_ALLOW_PENDING=1` 仅限本地临时绕过),并且该套件通过 ubuntu-latest 构建任务在每个 PR 上的 CI 中运行。93 个针对一月份已从本仓库移除的 `app.lib.*` 代码的孤立测试用例——自二月以来一直处于静默 pending 状态——已被移除;测试套件现在如实报告 4 个成功 / 0 个 pending。
