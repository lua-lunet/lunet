- **LuaCATS type annotations for the full public API** (#135, #136, #137, #138): `types/lunet/*.lua` now annotates every shipped module — including the previously missing `lnt_shared` (2 module functions + 13-method Dict object), `httpc`, `jsonic`, `postgres`, and `paxe` — each paired with a Teal `.d.tl` mirror that the repo keeps in lockstep by rule. The annotations ship inside every binary release archive as documentation, and a new CI gate validates them with lua-language-server: `xmake check-types` parses the JSON report (LuaLS 3.15+ exits 0 even with diagnostics) and fails on any warning-level diagnostic.
- **An honest Lua test gate**: `make test` now runs `check-types` first, builds `lunet-httpc`, then runs the busted suite under LuaJIT (5.1 ABI) — resolving the interpreter as `$LUNET_BUSTED` → `~/.luarocks/bin/busted` → PATH, because both Homebrew's and Debian's luarocks busted wrappers exec PUC Lua, which hangs loading lunet's LuaJIT-linked C modules. Any `pending` test fails the run (`LUNET_ALLOW_PENDING=1` is a local-only escape hatch), and the suite runs in CI on every PR via the ubuntu-latest build job. 93 orphaned test cases that asserted against `app.lib.*` code removed from this repository in January — silently pending since February — were removed; the suite now reports a truthful 4 successes / 0 pending.
